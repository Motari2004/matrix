# Matrix Illusion

🌧️ A mesmerizing **Matrix-style digital rain** animation — the iconic green cascading code from *The Matrix* movie, re-created as a modern web experience.

Built with **Next.js**, **TypeScript**, and custom CSS for smooth, performant fullscreen raining characters.

**Live Demo:**  
https://matrix-illusion.vercel.app  
(Wake up... Take the red pill or the blue pill? 😎)

## Features
- Classic Matrix digital rain effect (falling katakana, numbers & symbols)
- Fullscreen, responsive design
- Smooth animation optimized for desktop & mobile
- Next.js App Router for fast loading & SEO
- TypeScript for type-safe, maintainable code
- Custom CSS styling (no frameworks — pure control)
- Ready for extensions: interactive controls, color themes, speed adjustments, or even Prisma-powered features in the future!

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Plain/Custom CSS
- **Font**: Geist (via next/font — clean & modern)
- **Database/ORM** (optional/future): Prisma
- **Deployment**: Vercel
